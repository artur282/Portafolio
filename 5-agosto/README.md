# 🏆 Agosto — Capstone Projects

> _"El final es sólo el inicio cuando se entrega valor al ecosistema."_

## 🎯 Objetivo del mes

Desarrollar productos integradores (Capstone) cerrando con una plataforma comercial. Aprender cómo vender tecnología, documentarla mediante plataformas públicas autogeneradas y retribuir valor abriendo un ecosistema contribuyendo de vuelta al open-source.

---

## 📅 Proyectos del mes

### 🏗️ Proyecto Principal: [AutoPlatform](./proyecto-autoplatform.md)
Un motor de automatización estilo Zapier donde se modelan workflows que interactúan con LLMs. Presenta sus utilidades en un marketplace comercializado usando frontends avanzados (Next.js) que engloba además el desarrollo de un Portfolio profesional estático que resalta la reestructura. Incluye pull-requests a proyectos open source y documentación exhaustiva.

- **Tecnologías**: FastAPI, Next.js, Vercel, TailwindCSS, OSS
- **Estado**: ⬜ Pendiente

### 🤖 AI Track: [GuardAI](./mes-05-guardai.md)
Seguridad para Large Language Models in-depth (Hardening). Filtra datos personales (PII) antes de llegar al modelo usando Microsoft Presidio, bloquea ataques maliciosos usando NeMo Guardrails e instruye al agente de cómo manejar red-teaming (jailbreaks deliberados).

- **Tecnologías**: Presidio, NeMo Guardrails, Red-Teaming
- **Estado**: ⬜ Pendiente

---

## 🧠 Habilidades que se desarrollan

- Manejo End-to-End conceptual: desde el código fuente a la página de ventas.
- Dominio de motores de workflows utilizando Behavioral Strategy Patterns.
- Publicación web de aplicaciones estáticas en Vercel con custom domains y CDN.
- Contratos OSS formales: Forking, pull-requests formales resolviendo issues públicos.
- Defensibilidad sobre ataques Prompt Injection / Leakage a modelos abiertos en LLMs corporativos.
