# 🔗 Julio — Full-Stack Integration

> _"El verdadero poder está en conectar backend y frontend en experiencias completas."_

## 🎯 Objetivo del mes

Construir aplicaciones full-stack completas que combinan APIs robustas con interfaces modernas. Desde gestión de proyectos hasta dashboards en tiempo real y apps móviles con Flutter. En paralelo, construir una capa de seguridad para LLMs con guardrails y red-teaming.

## 🧠 Habilidades que se desarrollan

**Backend:**
- Desarrollo full-stack (React + FastAPI) con Layered Architecture
- Comunicación en tiempo real (WebSockets)
- Desarrollo móvil multiplataforma con Flutter 📱
- Procesamiento asíncrono con RabbitMQ y patrón SAGA
- Notificaciones multi-canal con idempotencia

**AI:**
- Detección y anonimización de PII con Microsoft Presidio
- Prompt injection prevention y prompt hardening
- NeMo Guardrails para políticas de contenido
- Red-teaming automatizado (50+ ataques adversariales)
- Cumplimiento GDPR: audit trail, right-to-erasure
