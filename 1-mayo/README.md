# 🤖 Mayo — IA/ML & GenAI

> _"Sistemas empresariales potenciados por inteligencia artificial real."_

## 🎯 Objetivo del mes

Desarrollar sistemas de gestión del conocimiento de grado de producción que combinan capacidades tradicionales de backend con motores avanzados de GenAI y LLMs. El enfoque está en crear plataformas útiles de RAG, búsquedas complejas y Agentes conversacionales.

---

## 📅 Proyectos del mes

### 🏗️ Proyecto Principal: [KnowledgeForge](./proyecto-knowledgeforge.md)
Plataforma enterprise de gestión de conocimiento. Ingesta documentos, los indexa con Elasticsearch (full-text) + pgvector (semántico) y ofrece Q&A vía RAG. También levanta un servidor MCP para exponer todas sus capacidades a modelos externos.

- **Tecnologías**: FastAPI, PostgreSQL, pgvector, LangChain, OpenAI, MCP SDK, Elasticsearch
- **Estado**: ⬜ Pendiente

---

## 🧠 Habilidades que se desarrollan

- Arquitecturas GenAI, embeddings, y RAG (Retrieval-Augmented Generation).
- Integraciones complejas con bases de datos vectoriales y motores full-text.
- Protocolo MCP (Model Context Protocol).
- Creación de APIs REST asíncronas con FastAPI.
- Versionado sistemático y evaluación estructurada de Prompts y LLM outputs.
