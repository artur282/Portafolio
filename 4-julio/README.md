# 🔗 Julio — Full-Stack Integration

> _"Sistemas donde el frontend vive, el backend procesa asincrónicamente y todo está sincronizado."_

## 🎯 Objetivo del mes

Combinar todas las partes del desarrollo moderno para crear un producto B2B/B2C interactivo de clase mundial. Integración de web, dispositivos móviles y backend orientada a eventos con tareas en segundo plano (workers).

---

## 📅 Proyectos del mes

### 🏗️ Proyecto Principal: [TeamSync](./proyecto-teamsync.md)
Plataforma colaborativa completa. Gestiona proyectos mediante una SPA Web React, sincroniza de forma global a los usuarios trabajando en línea a través de WebSockets, incluye notificaciones móviles con Flutter Push y usa Celery workers para el heavy lifting.

- **Tecnologías**: React, FastAPI, PostgreSQL, WebSockets, Flutter/Dart, RabbitMQ/Celery
- **Estado**: ⬜ Pendiente

### 🤖 AI Track: [AgentFlow](./mes-04-agentflow.md)
Agente empresarial multi-paso inteligente impulsado por LangGraph donde el modelo planifica y llama autónomamente a funciones a través de memoria persistente por ciclos largos.

- **Tecnologías**: LangGraph, OpenAI, Function Calling
- **Estado**: ⬜ Pendiente

---

## 🧠 Habilidades que se desarrollan

- Ecosistema Full-Stack integral (Arquitectura Frontend a Container DDBBs).
- State-management avanzado consumiendo WebSockets en tiempo real bidireccionales.
- Workers paralelos y sistema asíncrono robusto RabbitMQ (Advanced Message Queuing Protocol).
- Diseño SAGA distribuido para prevenir fallas a red entre múltiples servicios aislados.
- Desarrollo de Agentes Reactivos (ReAct) con grafos de lógica de máquina compleja.
