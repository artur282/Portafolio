# 🤖 Abril — IA/ML & GenAI

> _"La IA no reemplaza al ingeniero, lo potencia."_

## 🎯 Objetivo del mes

Demostrar capacidad para integrar inteligencia artificial en aplicaciones reales. Desde chatbots conversacionales hasta servidores MCP, pipelines RAG y motores de búsqueda con Elasticsearch. En paralelo, construir un pipeline RAG de producción con evaluación RAGAS.

## 🧠 Habilidades que se desarrollan

**Backend:**
- Integración de LLMs en aplicaciones backend (LangChain, OpenAI)
- Construcción de servidores MCP (Model Context Protocol)
- Pipelines RAG (Retrieval Augmented Generation)
- Motor de búsqueda con Elasticsearch (full-text, facets, autocompletado)
- Embeddings, Vector DBs (Chroma, pgvector) y búsqueda semántica

**AI:**
- RAG avanzado: chunking strategies (recursive, semantic, hierarchical)
- Evaluación de retrieval con RAGAS (faithfulness, answer relevancy)
- Búsqueda híbrida semántica + BM25
- Reranking con Cohere / Cross-encoder
