El gran cierre. Los proyectos capstone integran todo lo aprendido en los 5 meses anteriores en soluciones completas y ambiciosas. ## 🧠 Habilidades que se desarrollan

**Backend:**
- Arquitectura de sistemas complejos (GoF Patterns, Strategy)
- Integración de múltiples servicios y tecnologías
- Desarrollo de producto (MVP completo)
- Contribución a open source
- Documentación técnica profesional y portfolio

**AI:**
- Arquitectura completa AI: API Gateway → Agent → RAG → Guardrails → Observabilidad
- MLOps y CI/CD con evaluación automática en cada PR
- Model routing dinámico (GPT-4o vs mini por complejidad)
- Multi-tenancy, ADRs, playbooks de uso y retrospectiva
