# ☁️ Junio — DevOps, Cloud & Polyglotism

> _"La infraestructura resiliente es el puente entre una app local y escala global."_

## 🎯 Objetivo del mes

Entrar de lleno al mundo de microservicios robustos, seguridad perimetral y CI/CD automatizado continuo. Enseña a separar la capa principal de red (gateway) de servicios de hyper-rendimiento con comunicaciones inter-proceso binarias entre múltiples lenguajes (Polyglot).

---

## 📅 Proyectos del mes

### 🏗️ Proyecto Principal: [MicroGate](./proyecto-microgate.md)
Un gateway API resiliente en Python acoplado a un microservicio crítico de alto rendimiento en Rust comunicados fuertemente vía gRPC, todo orquestado y desplegado de forma totalmente automatizada.

- **Tecnologías**: Python/FastAPI, Rust/Axum, gRPC/Protobuf, Redis, JWT, GitHub Actions, Docker Distroless
- **Estado**: ⬜ Pendiente

### 🤖 AI Track: [EvalForge](./mes-03-evalforge.md)
Framework de evaluación y observabilidad de Inteligencia Artificial que implementa A/B testing para prompts y monitoreo intensivo a través de Langfuse.

- **Tecnologías**: Langfuse, RAGAS, Grafana
- **Estado**: ⬜ Pendiente

---

## 🧠 Habilidades que se desarrollan

- API Gateway Patterns: Rate Limiting, Central Auth, y Circuit Breaking optimizando cachés en Redis.
- Desarrollo híbrido (Polyglot): Compilación compartida ProtoBuf (`.proto`) entre repositorios.
- Optimización extrema de infraestructura creando imágenes Ultra-lights (Distroless de <30MB).
- Automatización e integración total usando GitHub Actions e infraestructura como código.
- Observabilidad GenAI y testeo riguroso contra datasets *golden*.
